# Compare & Contrast Essay Prewriting Workshop

A GitHub Pages-ready interactive prewriting workshop for a remedial/high-school English class.

## Student workflow
Students brainstorm two subjects, identify similarities and differences, plan two outside sources and three quotes, practice source integration and vocabulary, build a thesis/title, plan paragraphs, run a rubric-readiness check, and download both their complete responses and a clean working outline.

## Assignment settings built in
- Minimum essay length: 2 full pages
- Two outside sources
- At least three relevant quotes
- In-text citations and follow-up analysis
- Three or more vocabulary words
- Abstract and Works Cited planning
- Same general rubric structure as the class cause/effect assignment

## GitHub Pages
1. Create a repository.
2. Upload `index.html`.
3. In repository Settings > Pages, deploy from the main branch/root.
4. Share the published Pages URL with students.

Student entries autosave in that browser using localStorage. No responses are sent to a server.
